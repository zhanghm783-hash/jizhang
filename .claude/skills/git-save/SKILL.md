## 提交步骤

1. **摸清改动**：运行 `git status --short` 和 `git diff --stat`，了解这次要提交哪些文件。
   - 没有任何改动 → 直接告知用户无需提交，流程结束。
2. **生成提交说明**（中文）：
   - 第一行一句话说清"做了什么"，参考仓库历史风格，例如"新增贪吃蛇小游戏""添加质检技能与质检帮工，打包改为仅生成 exe 安装包"。
   - 改动较大时，附正文逐条列出要点（`git commit -m '第一行' -m '正文'`）。
3. **暂存**：`git add` 相关文件（通常 `git add -A`）。
4. **提交**：`git commit -m '...'` 执行提交。
5. **汇报结果**：提交成功 → 告知用户提交说明；提交失败 → 用大白话解释原因。

## 注意事项

- 提交会经过"提交前自动检查"关卡（要求单元测试和质检的通过标记都在）：
  - 被关卡拦下时，向用户解释原因，并引导用户对 Claude 说"帮我提交"，让 gitcommit-agent 重新跑一遍测试和质检；
  - **禁止用 `--no-verify` 硬闯**。
- 提交成功后标记会被关卡自动销毁，属正常现象，不要试图补写。
