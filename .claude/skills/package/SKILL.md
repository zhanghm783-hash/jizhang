## 打包步骤

1. **先告知用户**：打包需要几分钟（首次打包更久，可能 10 分钟以上），期间界面没反应属正常现象。
2. 在项目根目录（d:\黑马记账APP）运行打包命令：

   ```
   npm run tauri build
   ```

   这条命令会自动做三件事：检查代码 → 编译界面 → 编译并生成安装包。
3. 等命令跑完，看输出末尾是否出现打包成功的信息。
4. 打包成功后，安装包在 `src-tauri\target\release\bundle\nsis\` 目录下，是 `.exe` 安装包。
   （本项目只打 `.exe`：产品名"黑马记账"含中文，MSI 打包工具不支持中文会失败，这是已知原因，不要尝试切回 MSI。）
5. 把安装包所在路径和文件名告诉用户，建议用户双击安装试用。

## 打包失败时

- 用大白话向用户解释报错原因，不要直接改代码，先汇报再处理。
- 常见原因：Rust 环境问题、杀毒软件拦截、网络下载依赖失败。逐条排查并向用户说明每一步在做什么。

## 注意事项

- 安装包只能在对应系统上打包：Windows 电脑只能打 Windows 包，Mac 包必须在 Mac 电脑上打。
- 如果本次是发布新版本，先和用户确认是否需要更新 `src-tauri\tauri.conf.json` 里的版本号，再开始打包。
